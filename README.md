# 🌍 Air Quality Analysis in India

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on air quality data collected from different cities in India. The objective is to understand AQI patterns, analyze major air pollutants, compare air quality across cities, and identify trends over time.

## 📊 Dataset

- Total Records: 6,314
- Total Cities: 9
- Target Variable: AQI
- Key Feature: AQI_Bucket
- Major Pollutants: PM2.5, PM10, NO, NO2, NOx, NH3, CO, SO2, O3, Benzene, Toluene, Xylene

## 🔍 Analysis Performed

- Data loading and understanding
- Missing value analysis and treatment
- Duplicate value checking
- Numerical and categorical variable analysis
- Distribution analysis
- Outlier detection
- City-wise AQI analysis
- AQI category distribution
- Monthly AQI trend analysis
- Correlation analysis
- PM2.5 vs AQI analysis
- PM10 vs AQI analysis
- Average AQI comparison across cities

## 📈 Key Insights

- PM2.5 has a strong positive correlation with AQI (0.923).
- PM10 also has a very strong positive correlation with AQI (0.916).
- AQI varies across different cities and time periods.
- Moderate and Satisfactory AQI categories represent a large proportion of the observations.
- Correlation and scatter-plot analysis help identify the pollutants most strongly associated with AQI.

This project demonstrates how Python-based data cleaning, exploratory analysis, statistical correlation, and interactive visualization can be used to extract meaningful insights from real-world air-quality data.
